離散數學是計算機科學的**母語**。不同於連續數學（微積分），它處理的是**可數的、分離的**結構——這正是電腦的本質。

## 為什麼需要離散數學？

<Tip title="Why Discrete?">
電腦用 0 和 1 運作——沒有「中間值」。網路封包要嘛送達要嘛不送達。資料庫的查詢結果是離散的記錄。所以 CS 的數學基礎是離散的。
</Tip>

## 命題邏輯 (Propositional Logic)

```python
# 邏輯運算子在 Python 中
p = True
q = False

print(p and q)  # AND:  False
print(p or q)   # OR:   True
print(not p)    # NOT:  False
print(p ^ q)    # XOR:  True

# 邏輯等價：De Morgan's Law
# not (p and q) == (not p) or (not q)
print(not (p and q) == (not p) or (not q))  # True
```

| 運算 | 記號 | 中文 | 意義 |
|------|------|------|------|
| AND | ∧ | 且 | 兩者皆真才真 |
| OR | ∨ | 或 | 至少一個真 |
| NOT | ¬ | 非 | 反轉 |
| XOR | ⊕ | 互斥或 | 剛好一個真 |
| Implication | → | 蘊含 | 若 P 則 Q |

## 集合論 (Set Theory)

集合是一切資料結構的基礎。

```python
# Python 中的集合操作
A = {1, 2, 3, 4, 5}
B = {4, 5, 6, 7, 8}

print(A | B)   # Union:      {1,2,3,4,5,6,7,8}
print(A & B)   # Intersection: {4,5}
print(A - B)   # Difference:  {1,2,3}
print(A ^ B)   # Sym Diff:    {1,2,3,6,7,8}

# Subset check
print({1, 2}.issubset(A))  # True
print(A.issuperset({1, 2})) # True
```

## 圖論 (Graph Theory)

圖是 CS 最重要的抽象之一——從社交網路到路線規劃，無處不在。

```python
# 用 dictionary 表示圖 (adjacency list)
graph = {
    'A': ['B', 'C'],
    'B': ['A', 'D', 'E'],
    'C': ['A', 'F'],
    'D': ['B'],
    'E': ['B', 'F'],
    'F': ['C', 'E'],
}

# DFS (Depth-First Search)
def dfs(graph, start, visited=None):
    if visited is None:
        visited = set()
    visited.add(start)
    for neighbor in graph[start]:
        if neighbor not in visited:
            dfs(graph, neighbor, visited)
    return visited

print(dfs(graph, 'A'))  # {'A', 'B', 'C', 'D', 'E', 'F'}

# BFS (Breadth-First Search) — 最短路徑
from collections import deque

def bfs(graph, start, goal):
    queue = deque([(start, [start])])
    visited = {start}
    while queue:
        node, path = queue.popleft()
        if node == goal:
            return path
        for neighbor in graph[node]:
            if neighbor not in visited:
                visited.add(neighbor)
                queue.append((neighbor, path + [neighbor]))
    return None

print(bfs(graph, 'A', 'F'))  # ['A', 'C', 'F']
```
